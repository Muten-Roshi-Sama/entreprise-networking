# Network Administration Labs

This repository contains laboratory reports completed as part of the Network Administration and Networking course.

## Overview

The labs progressively build a complete network architecture composed of:

* A pfSense **firewall**
* An internal **LAN**
* A **DMZ**
* **Windows Active Directory** services
* Web services exposed through **reverse proxies**
* **VPN** access for remote users

Each report documents the deployment process, configuration choices, validation steps, troubleshooting, and final results.

## What Was Built

Throughout the different labs, I deployed and configured the following components:

* pfSense **firewall**
* Network segmentation (**WAN / LAN / DMZ**)
* Firewall and **NAT** rules
* **Windows** Server and **Active Directory**
* User and group management
* Group Policy Objects (**GPO**)
* **DNS** and **DHCP** services
* **Web server** deployment
* **Nginx reverse proxy** configuration
* **OpenVPN** remote access
* Network diagnostics and troubleshooting
